### واجهة Agents API
تتيح الواجهة الجديدة للمطورين استخدام البنية التحتية الخاصة بـ Codex لبناء وكلاء سحابيين يتميزون بـ:
- تشغيل المهام طويلة الأمد بشكل مستقل.
- تنسيق العمليات واستدعاء الأدوات الخارجية.
- تفويض المهام لوكلاء فرعيين (Sub-agents) داخل بيئات معزولة (Sandboxes).

### واجهة GPT-Live-1
- توفر تجربة صوتية طبيعية ومزدوجة الاتجاه (Full-duplex) تتيح التحدث والاستماع في وقت واحد.
- حققت نسبة 80.1% في اختبارات التفاعلية مقارنة بـ 45.4% للجيل السابق.
- تبلغ تكلفتها 0.05 دولار للقيقة مع دعم تخصيص الأصوات والربط بالشبكات الهاتفية.
